# Поздравительный квест

Мобильный сайт-поздравление для коллеги. Открывается по ссылке:
https://ukhinalizabiz-png.github.io/withBDTERRO/

Это статическая страница: обычный HTML, CSS и JavaScript, без сборки и
без сервера. Чтобы она жила дальше, репозиторий должен оставаться
публичным, а в настройках Pages источником — ветка `main`, папка `/`.

Посмотреть локально: `node serve.js` из соседней папки проекта, затем
http://localhost:5178
